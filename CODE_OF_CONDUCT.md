# Code of conduct

Help make GitNostics a respectful, useful collaboration space. Be considerate of different experiences, identities, skill levels, and communication styles. Give constructive technical feedback, cite evidence, and discuss the work rather than attacking the person.

Harassment, threats, discrimination, sexualized conduct, doxxing, and deliberate disruption are unacceptable. Do not publish another person's private information or credentials. These expectations apply in project issues, pull requests, discussions, and other spaces where someone represents the project.

Maintainers may edit or remove harmful content and temporarily or permanently restrict participation. They should explain moderation decisions where doing so does not expose confidential information and should handle reports fairly and privately.

Report conduct concerns privately to a maintainer through a contact method listed on that maintainer's GitHub profile. Do not disclose a report or personal details in a public issue. If no private contact method is available, ask a maintainer for a private reporting channel without posting the sensitive details.
